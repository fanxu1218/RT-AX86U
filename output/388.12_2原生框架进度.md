## 路线与本轮实现

完整继承固定的 AX86U 梅林 `3004.388.12_2` 镜像，源提交为 `433fc608f5fc1689f3d3c3ab5cd2a7d57102260f`。保留其匹配的启动/内核区域、内核模块、原生 rc、VPN 库、VPN 页面与其他原生功能；在此基础上增加受控的软件中心适配。原生 rc/httpd 原文件另存于只读系统目录，入口由适配启动器调用。没有将此前为官方底包编写的事件模拟器加载到梅林 rc。

已确认梅林原生 `ntpd_synced step` 中仍有 UU 启动路径；此前原厂 `ntp` 信号入口不能用于判断梅林是否保留了该路径。新增适配仅对大陆 RT-AX86U 路由模式补充 `uu_accel` 能力字，不覆盖其他梅林能力字，也不提交 NVRAM 到实际设备。

原生钩子先按上游接口执行用户脚本，再补充对应软件中心入口；两者共享每次事件独立的去重目录，保留用户脚本，不改写它们。非软件中心事件仍由梅林原生处理。软件中心准备失败或达到事件容量上限时，保留原生用户钩子，并停止追加本次软件中心调用。

保留完整梅林 `helper.sh`，包括附加组件设置与页面管理函数。DNS 兼容只增加软件中心使用的 `/jffs/configs/dnsmasq.d`，顺序位于原生自定义配置处理之后、用户 postconf 之前；重复执行不会重复添加目录。防火墙恢复适配不再重复合成梅林已经拥有的 NAT/防火墙事件。

## 本轮复现与修复

P2 的原生钩子增强确有同步语义缺口：原生调用返回时，追加的软件中心辅助脚本仍未完成。现保留原生用户脚本的调用方式，再按照剩余时限同步等待辅助脚本；原调用为异步时仍异步，正数时限耗尽后记录并停止追加。P4 中实际加载的 `/usr/lib/localmod/native_boot_bridge.so` 已通过三项对照，见 `merlin38812_sync_aux_tests.json`。旧复现与源码覆盖层验证分别保留，未当成镜像通过证明。

P3 又复现小数等待失败：原生与 HND 捐赠 BusyBox 均拒绝 `sleep 0.1`。P4 的恢复中止等待改用现有 `usleep`；软件中心专用 PATH 增加独立 `sleep` 工具，支持小数、多段时长和常用单位，拒绝负数、非有限值及无效输入。不覆盖系统 BusyBox 或插件自带工具；已通过实际工具执行和加载 `base.sh` 后的裸命令检查。测试中使用的 `command -v` 也被原生 ash 拒绝，现改为真实插件调用路径验证，属于测试夹具修正。P3 镜像、失败日志均保留。

Fancyss 的初次文件校验已按上游原生系统 JQ 分支修正；随后真实卸载复现共享链接丢失：FRPC/PushPlus 仍在时，卸载脚本会删除 `/koolshare/bin/jq` 的系统链接。系统 JQ 本体、UU 数据未丢失，P4 整套 Fancyss 共存检查当时未通过。P5 已修复适配包规则、包摘要及安装页面，36 项共存检查通过。失败日志为 `merlin38812_plugins_fancyss_shared_jq_before.log`。

P5 已将 Fancyss 适配包更新为 localmod2，保留共享 JQ 链接；包摘要和安装页 MD5/文件名同步更新。对于已安装且摘要匹配的原始/旧适配版卸载脚本，软件中心在检查点之后执行只读系统内的兼容卸载器，避免同版本跳过更新时继续删除共享链接。未知用户脚本不改写。

P4 的真实防火墙恢复适配器经声明的 Alpine legacy xtables 内核边界验证，连续 `--noflush` 确会使 INPUT 保护跳转变为 1、2、3；当时访问保护和 UU 均正常。P5 修复为同次 COMMIT 删除旧的自有跳转、重置链并只插入一条；已在镜像内程序上复测通过旧重复规则清理及无关 INPUT 规则保留，三轮跳转数量为 1、1、1。该测试不等同原厂 4.1 内核 ABI 验收。
