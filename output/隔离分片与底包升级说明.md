# 隔离测试分片与官方底包升级

此项改变本地验证与迁移检查流程，不改动已发布 r8 镜像，也不连接或刷写路由器。当前构建目标为尚待整合的 r9，最终结果必须以新镜像回读及与其 SHA256 绑定的报告为准。

## VM 输入和资源隔离

只读 VM 现在从明确的输入清单生成独立目录，不再导出整个工作仓库。清单包含待测根目录、必要的原厂程序夹具、测试程序和固定插件包；Git 数据、整个下载目录、旧私钥夹具目录和其他失败盘不进入导出。

每个 VM 都有自己的 phase 文件、程序和资源副本。APFS 支持时使用有独立 inode 的写时复制，其他情况实际复制，不以硬链接共享不可变输入。封存清单记录文件内容、类型、权限和链接目标，运行前后均核对；输入变化不会取得通过结果。清单最多 20000 项、768 MiB，暂存空间不足时停止并保留现场。

宿主导出仍只读，来宾没有外网网卡。跨进程文件锁最多允许两个只读 VM；并行分片每个使用 1 个 vCPU、1024 MiB 内存。锁描述符随 VM 子进程保留，取消仅终止对应的子进程。控制台上限 8 MiB，每个任务有独立时限。正常完成只清理该任务的专属目录；失败保留目录、清单、日志和运行回执。早期缺失夹具输入的失败副本可在逐项核验归档后保存为私有压缩包，不上传 GitHub。

持久化测试盘仅允许本流程生成的 96 MiB、权限 0600 的文件。原盘加独占锁后复制到当前 VM 的专属目录，VM 结束后核验原文件身份并同步写回，供下一次启动使用；另一个任务不能同时接管同一原盘。盘内容变化不属于不可变输入，路径、类型、容量和权限仍受检查。宿主流程异常退出时，应从保留的任务目录检查工作盘，不能把未完成写回当作通过。该机制仅管理合成测试数据，不访问真实路由器数据。

明确支持并行的是 `check_hardening.py` 的六个分片与 `check_shards.py` 的隔离验证。旧检查器的编译、覆盖层和输入准备仍按顺序执行；不要任意并发运行两个 `check_*.py`，也不要在校验期间修改其绑定的源码。生产镜像组装和需要宿主写入的早期模型检查仍顺序运行。

## 分片验证

```sh
python3 build/check_shards.py
python3 build/check_history.py
```

前者在 r8 上使用明确记录的源码覆盖层，检查真实原厂状态接口与 UU 故障恢复同时运行、第三个 VM 排队限制、排队取消、单 VM 取消、同伴继续运行、启动前/结束后的封存篡改拒绝及现场保留。后者用六次独立启动验证新执行器下的持久盘状态、历史记录和插件/UU 哨兵。最终 r9 分别使用 `--candidate`，报告不得冒用覆盖层结果。

本地覆盖层已通过 12 项分片检查和六次启动的 85 次历史记录阶段断言。底包重新提取为零差异，13 项审计断言通过。报告分别绑定实际底包、输入清单与脚本哈希；候选镜像尚需另行构建和完整验证。

## 官方底包升级检查

官方更新仍需生成新的官改镜像，但可以复用已有适配代码、固定插件包、检查点逻辑和测试。新增检查入口负责指出变化及必须复核的接口，不会直接覆盖底包、依赖锁、版本配置或已有发布：

```sh
analysis/.venv/bin/python build/base_migration.py --image /完整路径/华硕官方固件.w --output /完整路径/底包差异报告.json
```

工具先核对固定 24437 的镜像、元数据和原厂根目录指纹，再从所选镜像重新分离 UBI/UBIFS、校验 CRC 并独立提取内容和 inode 权限/所有者。仅接受普通 RT-AX86U 的型号字段；版本字段变化不被误当作型号变化。

报告比较路径、文件内容、链接、权限、所有者、启动区和内核模块；同时检查 ARM32 小端 ABI、原厂登录认证导出、rc 导入、共享文件查询函数、TLS 重试与缓存所需符号，以及原厂 UU/登录页面的流程标记。相同镜像必须得到相同清单；控制用例实际改变一次性提取目录中的 ELF 机型和 TLS 符号，确认检查拒绝，再恢复原字节。接口或文件缺失时停止并保留提取现场。

符号及字符串存在只能证明迁移的必要条件。任何不同的官方镜像都标记为需要重新构建，即使上述接口仍在，也必须审查版本/依赖锁、`release_config.py`、底包目录、组装与回读脚本中绑定 24437 的位置，再执行完整门禁。TLS、认证、UU 行为和内核差异不能靠符号名自动判断兼容。

建议每次保留官方原包和旧官改发布，在独立目录审查差异，针对改变的接口调整适配代码，构建新版本并回读，完成软件中心、Fancyss、DDNS-Go、UU、TLS 和恢复回归后再发布新的实验候选。实机升级仍先备份，按验收文档测试；直接刷回官方固件会覆盖镜像内的官改组件。

本地 Alpine/QEMU、受控账号和无外网夹具不能替代原厂内核、无线/NAT、真实 UU/代理流量、物理断电或实机升级验收。
